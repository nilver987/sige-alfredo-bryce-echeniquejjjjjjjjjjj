# Sesión 1: ¿Qué es programar?

Programar es darle instrucciones a una computadora para que haga una tarea. La computadora, el celular o una consola son máquinas muy rápidas, pero no piensan por sí solas: solo hacen lo que alguien les indicó, paso a paso y en el orden correcto. Esas instrucciones se escriben en un **lenguaje de programación** (como Python o JavaScript), que es el idioma que la máquina entiende, y el conjunto de instrucciones se llama **programa**.

Gracias a la programación existen las apps del celular, los videojuegos, las páginas web y hasta los cajeros automáticos. Aprender a programar es aprender a explicarle las cosas a la computadora de forma clara y exacta.
